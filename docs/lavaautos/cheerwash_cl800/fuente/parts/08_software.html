Lo que el sistema propio hace

  • 4 programas editables paso a paso (presión alta/media/baja, tiempos, espumas, secado rápido o completo).
  • Contador de lavados (total y por rango), registro de alarmas con fecha y código, autotest al encender, permisos de operación por usuario.
  • Parada de emergencia, protección por falta de agua, fuga a tierra, anticolisión doble.
  • App móvil que replica la pantalla del HMI (ver estado, alarmas, últimos lavados) con el router que proveen.
  • Actualizaciones gratuitas del programa por vía remota; diagnóstico remoto con "PLC downloader".
  • Idiomas: HMI, pantalla LED y voz en español sin cargo.

Lo que no hace (y necesitamos para CARWASH Control)

  • No mide consumo de agua ni de electricidad por lavado, ni niveles de bidones: hay que instrumentar (caudalímetro, medidor trifásico, sensores de nivel).
  • No hay nube multi-sede ni reportes de ingresos: la app es un espejo del HMI.
  • La API "se entrega cuando llegue la máquina"; Victor recomendó no desarrollar hasta tenerla.

Integración de pagos: lo que sí está documentado

Opción 1, contactos secos: el dispositivo de pago cierra 1 segundo una entrada del PLC (Pago 1–4 = Programa 1–4); el PLC devuelve una salida "listo / ocupado o falla" para bloquear cobros.

Opción 2, Modbus: RS-485 (Modbus RTU) o Ethernet (Modbus TCP, IP 192.168.15.10, puerto 502). Registro 40001: escribir 1–4 arranca el programa 1–4. Registro 40002: 0 = se puede arrancar, 1 = ocupado. Si el dispositivo de pago no habla Modbus, un gateway IoT convierte el protocolo.

Fuente: "Payment Device Connection Diagram" (Cheer Wash). Esto es exactamente lo que necesita nuestra app para vender por QR de Mercado Pago y arrancar la máquina: un webhook de pago aprobado → escritura Modbus del programa. El módulo de USD 455 + 750 de soporte hace lo mismo con hardware de Cheer Wash.

Pedido concreto a Victor: el mapa completo de registros Modbus del PLC (no solo 40001/40002): contador de lavados, programa en curso, paso actual, código de alarma, estado de sensores, tiempo de ciclo. Con eso, CARWASH Control lee la máquina sin tocar el programa del PLC.
