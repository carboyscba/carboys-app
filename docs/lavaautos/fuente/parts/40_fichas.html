Las fichas usan los datos oficiales de cada fabricante cuando existen; donde no, se indica "est." (estimación propia) o "no publicado". Las citas de operadores provienen de carwashforum.com (EE. UU./Irlanda), foros alemanes e italianos, prensa sectorial (Surtidores.com.ar, CarwashPro, Sprit+) y reseñas públicas; cada una lleva autor, fecha y fuente.

Cómo usar las fichas

  1. Leer el veredicto y los puntajes: dicen si la máquina es candidata, referencia o descarte.
  2. Comparar la ficha técnica con la obra disponible (altura libre, largo de rieles, potencia).
  3. Usar el bloque de contacto para pedir cotización con el pliego del capítulo 8.4.
  4. Leer "lo que dice la gente" antes de negociar: ahí están las preguntas incómodas para el vendedor.
